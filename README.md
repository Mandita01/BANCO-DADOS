# Fonte de Informação e Banco de Dados

## 📊 Projeto PROCON

Este projeto tem como objetivo explorar e compreender dados abertos do PROCON com foco em identificar padrões, tendências e indicadores relevantes sobre denúncias e conflitos de consumo. A análise foi estruturada para transformar dados brutos em informações úteis para tomada de decisão e entendimento do cenário de consumo.

### Objetivo geral
- Explorar e organizar os dados do PROCON;
- Visualizar indicadores relevantes em dashboard;
- Identificar regiões, categorias e recorrências nas denúncias;
- Transformar dados brutos em informações estratégicas para análise.

### Fonte dos dados
- Arquivo principal: `Procon-Dadosdenuncia.xlsx`

## 🍦 Análise de vendas de sorvete

A análise observa a relação entre a **temperatura** e a **receita das vendas de sorvete**. No gráfico, cada ponto representa um registro: a temperatura aparece no eixo horizontal e a receita, no eixo vertical. A linha de tendência indica uma relação positiva: em geral, temperaturas mais altas estão associadas a receitas maiores.

Isso sugere que o calor pode estar relacionado ao aumento das vendas, mas não prova que seja a única causa. Promoções, localização e quantidade de clientes também podem influenciar os resultados. A moeda usada para registrar a receita deve ser confirmada na fonte dos dados.
